## 2. 画面

PC でもスマホと同じ幅（430px まで）の一列で出す。

出欠の色は、出席が青、遅刻・早退が薄い青、欠席が橙、未回答が灰色の輪。入力のボタン、札、人数の点、帯のすべてでこの決まりを使う。

### 2.1 登録とログイン

はじめに開くのはログインの画面。暗証番号の欄の下に小さく「はじめての方は 登録」があり、押すと登録の画面に移る。登録の画面の下には「登録済みの方は ログイン」がある。パスキーのボタンのさらに下に、目立たない「管理者の方」がある。

i ボタンは練習室予約システムと同じ作り。細い線の丸に i を描いた小さなボタンで、説明は薄い灰色の小さな札（ダークモードでは濃い灰色）で出す。指の端末では押すと出て、もう一度押すか、ほかの場所を押すと消える。マウスのある端末ではボタンの上にしばらく止めると出て、外れると消える。札は画面の端からはみ出さない位置に出し、画面を動かすと消える。

- 登録: 合言葉、氏名、パート、暗証番号（4〜8桁の数字）を入れて登録する。同じ氏名はほかの人が使えない。氏名の前後の空白は除き、途中の空白は全角1つにそろえる。
- ログイン: 氏名と暗証番号の欄と「暗証番号でログイン」を上に置き、親指で押しやすい画面の下の端に「パスキーでログイン」を大きく出す（パスキーを使えるブラウザだけ）。押すと端末の指紋・顔・画面ロックで本人を確かめ、氏名も暗証番号も入れずに入れる。合言葉は登録のときだけ入れる。
- 登録のすぐあとと、パスキーを持っていない人が暗証番号でログインしたすぐあとに「パスキーを作りますか」の画面を出す。「作る」で作ってホームへ、「あとで」でそのままホームへ進む。見出しの横の i ボタンで「指紋や顔、画面ロックでログインできるようになります。暗証番号でのログインも使えます。」が出る。設定のパスキーの欄の i ボタンでも同じ。
- ログイン画面の一番下の「管理者の方」から、管理用パスワードでログインできる（URL の末尾に `#admin` を付けても同じ）。

合言葉がまだ決まっていないときは、登録の画面に「まだ登録を受け付けていません。」と出る。ログインの印は端末に残り、180日使わなければログインし直しになる。

### 2.2 下のタブ

ログインしていると、画面の下に練習日・一覧・管理のタブが出る。管理のタブは役職と管理者にだけ出る。管理用パスワードで入ったときは、一覧と管理だけ。

### 2.3 練習日（ホーム）

上の切り替えで、リストと月のカレンダーを行き来する。

- リスト: 今日以降でいちばん近い練習日を「次の練習」として一つ大きく出し、その先を月ごとに区切って日付の順に並べる。右に自分の出欠（出席・遅刻・早退・欠席・未回答。遅刻と早退は時刻も）を出す。まだ答えていない日の札は枠つきで目立たせる。過去の練習日は下のボタンで開く。
- カレンダー: 練習日のマスに自分の出欠の色の点が付く（出席は青、遅刻・早退は薄い青、欠席は橙、未回答は灰色の輪）。今日の日付は黒丸。同じ日に練習が2つあるときは、先に始まる方を開く。

練習日を押すと出欠の入力に進む。右上の氏名（下向きの印つき）を押すと、設定とログアウトが出る。

設定では氏名とパートを変えられる。下のパスキーの欄に、自分のパスキーを作った日と最後に使った日が並び、消せる。「パスキーを作る」で足せる（一人10個まで）。

### 2.4 出欠の入力

戻るボタンは日付の見出しと同じ行にある。出席・遅刻・早退・欠席の四つから選ぶ。ボタンには出欠の色の点が付き、選ぶとその色で塗られる。出席は押しただけで送り、ホームに戻る。遅刻と早退を選ぶと時刻の欄（任意）が、欠席を選ぶと理由の欄（任意、200字まで）が出て、送信で送る。遅刻・早退の時刻は誰にでも見える。i ボタンで「理由を読めるのは本人と役職・管理者だけです。」が出る。過ぎた練習日は変えられない（ボタンが押せない）。

### 2.5 パート別の出欠

練習日を上の並びかカレンダーのボタンから選ぶ。最初は今日以降でいちばん近い練習日。出席・遅刻と早退・欠席・未回答の人数（名前の前に色の点）と帯、全体・弦・管打の絞り込み、パートごとの一覧を出す。団員のいないパートは出さない。パートごとの一覧には、欠席・遅刻・早退・未回答の人の名前を先に並べ、出席の人は「出席 n人」の1行にまとめる。押すと名前が出る。

役職と管理者には、欠席の人の理由が出る（記入がなければ「理由の記入なし」）。「理由を隠す」で隠せる。団員には自分の理由だけが出る。

### 2.6 管理

上の切り替えで、練習日・団員・パート・記録を行き来する。役職には練習日だけが出る（切り替えは出ない）。

- 練習日（役職と管理者）: カレンダーで日付を何日でも押して選び、種類（合奏・分奏などの候補あり、自由に書ける）、開始と終了の時刻、メモをまとめて付けて足す（一度に100日まで）。曜日を押すと、その月のその曜日のうち今日以降の日をまとめて選ぶ（全部選ばれていれば外す）。すでに練習日のある日には点が付く。足したあとも種類・時刻・メモは欄に残る。一覧の「複製」でその日の種類・時刻・メモを足す欄に写し、「直す」で一つずつ直し、「消す」でその日の出欠ごと消す。
- 団員: 合言葉を変える（4〜64文字。変えても、すでにログインしている人はそのまま使える）。団員はパートごとにまとめ、パートの並び順に出す。団員の役割（団員・役職・管理者）を変える。左の印で団員を選び、「n人を消す」でまとめて消す。消すと出欠の記録・ログイン・パスキーも消える。暗証番号を忘れた人は、消してから登録し直してもらう。最後の管理者は、団員としてのログインからは消せない・外せない（管理用パスワードのログインからはできる）。
- パート: 弦と管打のパートを並べ、人数を出す。団員のいないパートは消せる。名前（英数字8文字まで）と弦か管打を選んで足すと、その組の最後に入る。
- 記録: CSV の書き出し。すべての練習日と団員の組み合わせを1行ずつ（日付・種類・開始・終了・氏名・パート・出欠・時刻・欠席理由・回答日時）。Excel で開けるよう先頭に BOM を付ける。「年度で消す」は、終わった年度（4月から翌年3月）を選んで「書き出して消す」を押すと、その年度の分の CSV を保存させてから、確かめたうえでその年度の練習日と出欠を消す。

## 3. サーバー

### 3.1 呼び出し

`POST /api`、本文は `{ "action": "…", "params": { … } }`、ログインの印は `Authorization: Bearer …`。応答は `{ ok: true, … }` か `{ ok: false, code, message }`。呼び出せるのは画面のサイト（wrangler.toml の ALLOWED_ORIGIN、https://miyakyo-orchestra.github.io）からだけで、ほかのサイトからの呼び出しは断る。ログインの印を Authorization に入れて送るので、ブラウザは先に OPTIONS で確かめてくる。

| action | 使える人 | 内容 |
| :--- | :--- | :--- |
| info | 誰でも | パートの一覧、登録を受け付けているか |
| register | 誰でも（合言葉） | 団員の登録 |
| login | 誰でも | 団員のログイン（応答の hasPasskey でパスキーを持っているかを返す） |
| passkeyLoginOptions・passkeyLogin | 誰でも | パスキーでのログイン |
| adminLogin | 誰でも（管理用パスワード） | 管理用パスワードでのログイン |
| home | ログイン中 | 自分、今日の日付（日本時間）、練習日、自分の出欠 |
| logout | ログイン中 | ログインの印を消す |
| roster | ログイン中 | 練習日ごとの全員の出欠。理由は本人・役職・管理者にだけ入れる |
| answer | 団員 | 出欠の入力（status は attend・late・early・absent。late と early は at に時刻） |
| updateProfile | 団員 | 氏名とパートの変更 |
| passkeys・passkeyRegisterOptions・passkeyRegister・passkeyDelete | 団員 | 自分のパスキーの一覧・作成・削除 |
| adminData・saveDay・saveDays・deleteDay | 役職・管理者 | 練習日の管理（adminData は役職には練習日だけを返す。saveDays は練習日をまとめて足す） |
| setRole・deleteMember・deleteMembers・setPassphrase・addPart・deletePart・exportCsv・deleteYear | 管理者 | 管理の操作（exportCsv と deleteYear は year で年度を選ぶ） |

### 3.2 守り

- 暗証番号と合言葉は PBKDF2（20000回）で元に戻せない形にして置く。ログインの印は SHA-256 にして置く。
- パスキーは WebAuthn の仕組みで、端末の中の秘密の鍵による署名を、登録のときに受け取った公開鍵で確かめる。サーバーに置くのは公開鍵だけ。相手のサイトは ALLOWED_ORIGIN（rpId はその名前、https://miyakyo-orchestra.github.io なら miyakyo-orchestra.github.io）で、ほかのサイトからの署名は通らない。チャレンジは5分で切れ、一度しか使えない。端末で本人を確かめた印（UV）がないものは通さない。作るときに認証器の証明（attestation）は求めない。
- 暗証番号を5回続けて間違えると、その団員は10分ログインできない。
- 合言葉・管理用パスワード・ログインの氏名か暗証番号・パスキーでのログインを、同じ接続元から合わせて10回続けて間違えると、10分止める。

### 3.3 データ

Durable Object（名前 main）の SQLite の表: members（団員）、days（練習日）、answers（出欠）、sessions（ログインの印）、passkeys（パスキーの公開鍵）、kv（合言葉・入力ミスの回数・パスキーのチャレンジ）。Cloudflare が自動で控えを取り、30日前までの状態に戻せる。

## 4. パート

はじめは弦が Vn・Va・Vc・Cb（1stと2ndは分けない）、管打が Fl・Ob・Cl・Fg・Hr・Tp・Tb・Tuba・Perc。`src/store.js` の PARTS に書いてあり、管理画面で変えると kv の parts に置いた一覧を使う。以前 Vn1・Vn2 で登録した人は、サーバーが起きたときに Vn に直る。
