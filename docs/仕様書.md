## 2. 画面

### 2.1 登録とログイン

「登録」と「ログイン」を上の切り替えで選ぶ。

- 登録: 合言葉、氏名、パート、暗証番号（4〜8桁の数字）を入れて登録する。同じ氏名はほかの人が使えない。氏名の前後の空白は除き、途中の空白は全角1つにそろえる。
- ログイン: 合言葉、氏名、暗証番号。
- ログインの下の「管理者」から、管理用パスワードでログインできる（URL の末尾に `#admin` を付けても同じ）。

合言葉がまだ決まっていないときは「まだ登録を受け付けていません。」と出る。ログインの印は端末に残り、180日使わなければログインし直しになる。

### 2.2 練習日（ホーム）

上の切り替えで、リストと月のカレンダーを行き来する。

- リスト: 今日以降の練習日を日付の順に並べ、右に自分の出欠（出席・欠席・未回答）を出す。過去の練習日は下のボタンで開く。
- カレンダー: 練習日のマスに自分の出欠の色の点が付く（出席は青、欠席は橙、未回答は灰色の輪）。今日の日付は黒丸。同じ日に練習が2つあるときは、先に始まる方を開く。

練習日を押すと出欠の入力に進む。右上の氏名を押すと、氏名とパートの変更、管理（管理者だけ）、ログアウトが出る。

### 2.3 出欠の入力

出席か欠席を選んで送信する。欠席を選んだときだけ理由の欄（任意、200字まで）が出る。i ボタンで「理由を読めるのは本人と役職・管理者だけです。」が出る。過ぎた練習日は変えられない（ボタンが押せない）。

### 2.4 パート別の出欠

練習日を上の並びかカレンダーのボタンから選ぶ。最初は今日以降でいちばん近い練習日。出席・欠席・未回答の人数と帯、全体・弦・管打の絞り込み、パートごとの一覧を出す。団員のいないパートは出さない。

役職と管理者には、欠席の人の理由が出る（記入がなければ「理由の記入なし」）。「理由を隠す」で隠せる。団員には自分の理由だけが出る。

### 2.5 管理（管理者だけ）

- 練習日を足す。カレンダーで日付を何日でも押して選び、種類（合奏・分奏などの候補あり、自由に書ける）、開始と終了の時刻、メモをまとめて付けて足す（一度に100日まで）。曜日を押すと、その月のその曜日のうち今日以降の日をまとめて選ぶ（全部選ばれていれば外す）。すでに練習日のある日には点が付く。足したあとも種類・時刻・メモは欄に残る。
- 練習日の一覧の「複製」で、その日の種類・時刻・メモを足す欄に写す。「直す」で日付などを一つずつ直す。「消す」でその日の出欠ごと消す。
- 団員の役割（団員・役職・管理者）を変える、団員を消す。消すと出欠の記録とログインも消える。暗証番号を忘れた人は、消してから登録し直してもらう。最後の管理者は、団員としてのログインからは外せない（管理用パスワードのログインからは外せる）。
- 管理用パスワードで入ったときは「自分を団員として登録」が出る。氏名・パート・暗証番号を入れると、合言葉なしで管理者の団員として登録され、そのまま団員としてログインした状態になる。
- 合言葉を変える（4〜64文字）。変えても、すでにログインしている人はそのまま使える。
- CSV の書き出し。すべての練習日と団員の組み合わせを1行ずつ（日付・種類・開始・終了・氏名・パート・出欠・欠席理由・回答日時）。Excel で開けるよう先頭に BOM を付ける。

## 3. サーバー

### 3.1 呼び出し

`POST /api`、本文は `{ "action": "…", "params": { … } }`、ログインの印は `Authorization: Bearer …`。応答は `{ ok: true, … }` か `{ ok: false, code, message }`。呼び出せるのは画面のサイト（wrangler.toml の ALLOWED_ORIGIN、https://miyakyo-orchestra.github.io）からだけで、ほかのサイトからの呼び出しは断る。ログインの印を Authorization に入れて送るので、ブラウザは先に OPTIONS で確かめてくる。

| action | 使える人 | 内容 |
| :--- | :--- | :--- |
| info | 誰でも | パートの一覧、登録を受け付けているか |
| register | 誰でも（合言葉） | 団員の登録 |
| login | 誰でも（合言葉） | 団員のログイン |
| adminLogin | 誰でも（管理用パスワード） | 管理用パスワードでのログイン |
| home | ログイン中 | 自分、今日の日付（日本時間）、練習日、自分の出欠 |
| logout | ログイン中 | ログインの印を消す |
| roster | ログイン中 | 練習日ごとの全員の出欠。理由は本人・役職・管理者にだけ入れる |
| answer | 団員 | 出欠の入力 |
| updateProfile | 団員 | 氏名とパートの変更 |
| adminData・saveDay・saveDays・deleteDay・setRole・deleteMember・setPassphrase・exportCsv | 管理者 | 管理の操作（saveDays は練習日をまとめて足す） |
| registerSelf | 管理用パスワードでのログイン | 自分を管理者の団員として登録する |

### 3.2 守り

- 暗証番号と合言葉は PBKDF2（20000回）で元に戻せない形にして置く。ログインの印は SHA-256 にして置く。
- 暗証番号を5回続けて間違えると、その団員は10分ログインできない。
- 合言葉・管理用パスワード・登録のない氏名でのログインを、同じ接続元から10回続けて間違えると、10分止める。

### 3.3 データ

Durable Object（名前 main）の SQLite の表: members（団員）、days（練習日）、answers（出欠）、sessions（ログインの印）、kv（合言葉・入力ミスの回数）。Cloudflare が自動で控えを取り、30日前までの状態に戻せる。

## 4. パート

弦は Vn・Va・Vc・Cb（1stと2ndは分けない）、管打は Fl・Ob・Cl・Fg・Hr・Tp・Tb・Perc。`src/store.js` の PARTS で決めている。以前 Vn1・Vn2 で登録した人は、サーバーが起きたときに Vn に直る。
